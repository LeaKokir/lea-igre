# Lea Igre 🎮 — Uazalenje Games

Svaka igra ima svoj kanal:

- `#wordle` → `WORDLE_CHANNEL_ID`
- `#anagram` → `ANAGRAM_CHANNEL_ID`
- `#brzina` → `BRZINA_CHANNEL_ID`
- `#reakcija` → `REAKCIJA_CHANNEL_ID`
- `#games-leaderboard` → `LEADERBOARD_CHANNEL_ID`

Komande:
`/wordle`, `/pogodi`, `/wordle-igra`, `/wordle-stats`, `/wordle-top`
`/anagram`, `/anagram-pogodi`
`/brzina`, `/brzina-pogodi`
`/reakcija`
`/igre`, `/leaderboard`

XP i coins su zajednički kroz sve igre.

## Railway Variables

```text
DISCORD_TOKEN
CLIENT_ID
GUILD_ID
WORDLE_CHANNEL_ID
ANAGRAM_CHANNEL_ID
BRZINA_CHANNEL_ID
REAKCIJA_CHANNEL_ID
LEADERBOARD_CHANNEL_ID
```

Za postojeći Railway projekat Root Directory ostaje `/wordle`.
